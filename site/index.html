repocast

Turn any repo's changes into accurate, ready-to-post X posts, and post them safely.

For people building bots that post on X about code changes. It formats posts and threads to X's weighted 280-character limit and refuses any post with a number that doesn't trace back to the change data. It then posts through the X API v2 (OAuth 1.0a, threaded replies, account check), writes to an outbox, or does a dry run. Pairs with knoblog, which turns parameter and config diffs into structured change data.

pip install repocast
repocast preview -i site/feed.json      # knoblog output
repocast run -c repocast.toml           # dry run unless REPOCAST_LIVE=true

Safety built in

  • Accuracy gate: every number checked; no @mentions, hashtags or auto-linked bare domains
  • Dedup state, per-run and per-day caps, quiet hours, kill switch, no backfill
  • Off unless REPOCAST_LIVE=true; refuses to post unless GET /2/users/me matches the configured account
  • Never retries a post whose outcome is unknown
